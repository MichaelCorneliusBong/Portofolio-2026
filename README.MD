# Portofolio Web Application

Portofolio berbasis web yang dibangun menggunakan Laravel. Project ini digunakan untuk menampilkan data portofolio, informasi proyek, form contact, dan pengelolaan konten melalui dashboard admin.

---

## Tech Stack

- Laravel
- PHP
- Blade Template Engine
- MariaDB
- Docker
- Nginx
- Bootstrap / Tailwind CSS

---

## Fitur Utama

### User Side

- Halaman beranda portofolio
- Tampilan daftar proyek
- Detail proyek
- Halaman contact menuju database

### Admin Side

- Login admin
- Dashboard admin
- CRUD data proyek / portofolio
